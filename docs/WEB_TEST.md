# 웹 ChatGPT 사용 검증 안내

## 현재 상태

이 저장소의 planning-assistant는 스킬과 참고자료로 구성되어 있으며 MCP 서버, 회사 자료 또는 Google Drive 연결을 포함하지 않습니다. GitHub 공개 저장소를 만든 것만으로 ChatGPT 플러그인 디렉터리에 자동 게시되거나 웹에서 설치되는 것은 아닙니다. 무료 계정에서 이 패키지의 설치·공유 여부는 아직 실제 시험하지 않았습니다.

## 실제 계정별 확인 절차

검증에는 비민감 공개 시험자료만 사용합니다. 웹 ChatGPT의 실제 계정에서 각 단계의 날짜, 계정 종류, 버튼 유무, 결과와 오류를 기록합니다. 사용자 화면에서 없는 기능을 지원된다고 가정하지 않습니다.

1. 플러그인 목록에서 자비스를 제공받았는지 확인합니다. 목록에 없으면 설치 실패 또는 미제공으로 기록하고, GitHub URL만으로 설치되었다고 판단하지 않습니다.
2. 설치된 상태에서 새 대화에 스킬을 명시적으로 선택하거나 ‘자비스, 가상 사업 아이디어를 검토해 줘’라고 요청합니다. 어떤 지침이 적용됐는지, 확인되지 않은 실적을 창작하는지 확인합니다. 자연어 호출은 보장하지 않습니다.
3. 회사 공용 Drive 연결을 별도로 제공받고 계정별로 로그인한 경우에만 공개 시험 파일을 찾아보게 합니다. 검색·읽기와 생성·수정은 서로 다른 권한과 지원 여부를 따로 확인합니다. 연결 전후 권한 없는 파일이 차단되는지 확인합니다. 공유 드라이브에 실제 회사 자료를 넣기 전에 조직의 승인을 받습니다.
4. 공고 PDF와 신청 양식을 제공해 항목 순서, 근거, 미확인 사항을 확인합니다. 생성 가능한 파일 형식과 HWP·HWPX를 실제로 읽거나 변환할 수 있는지 따로 확인합니다. 변환 도구가 없다면 PDF나 DOCX를 직접 제공하는 우회 경로를 시험합니다.
5. 출력 PDF를 생성할 수 있다면 열어서 페이지 누락·한글 표시·표·가독성을 확인합니다. PDF를 만들 수 없거나 외형을 검토할 수 없으면 각각 미지원 또는 미검증으로 기록합니다.

## 배포 경로와 제한

Codex 로컬 마켓플레이스 설치와 ChatGPT 웹 제공은 서로 다른 배포 경로입니다. 공개 디렉터리나 워크스페이스에 제공하려면 각각의 이용 조건과 필요한 검토·승인을 확인해야 합니다. 회사 내부 인원에게만 제공하려는 목적과 공개 배포는 다릅니다. 계정의 플랜, 지역, 워크스페이스와 정책에 따라 기능이 달라질 수 있으므로 모든 무료 계정에서 동작한다고 약속하지 않습니다.
