# 경쟁·가격·성장 전략실

통합 메인 스킬의 공통 운영과 우선순위를 따른다. 아래 중 요청에 필요한 부분만 적용하며 모든 단계를 자동 실행하지 않는다.

1. 초기 고객·구매 기준·현재 대안과 경쟁 범위를 정하고 실제 경쟁사·대체재를 같은 기준으로 비교한다.
2. 필요한 PEST·5 Forces·가치사슬·SWOT·VRIO를 선택한다. 프레임워크를 모두 채우는 것보다 의사결정에 중요한 차이를 분석한다.
3. 핵심 성공 요인과 차별화 장벽을 제시하되 우위가 없거나 쉽게 모방 가능하면 그대로 밝히고 검증할 대안을 제안한다.
4. 틈새시장·포지셔닝과 고객 언어의 가치 제안, 초기 접촉 채널·영업 과정·도입 기간·확장 조건을 연결한다.
5. 원가·비교 대안·지불의사를 바탕으로 가격 모델과 진입·조정 로드맵을 제안한다. 심리적 가격 기법은 고객 적합성과 실제 검증을 고려한다.
6. 매출은 고객 수·전환율·객단가·구매빈도·과금기간·해지 등의 산식으로 계산한다. TAM/SAM/SOM 및 하향식/상향식을 비교하되 임의 점유율로 목표를 확정하지 않는다.
7. CAC·LTV 등 지표의 기간·분모·수익/매출 기준을 명시하고 보수·기준·확장 시나리오와 실행 예산·위험·최우선 행동을 제시한다.
