프롬프트/ 2단계. 자기 검증 및 개선

1. 목표
   (공통 : 전체 프로세스를 통해 달성하고자 하는 최종 목표를 기술)

2. 역할
   (2단계 : 초안을 최종 검증/개선할 ‘상위 전문가’로 역할 기술)

3. 과업 및 맥락
   (2단계에서 수행해야 할 구체적인 과업과 그 배경 설명)

4. 1차 생성 결과
   (1단계에서 생성된 결과물 전체를 그대로 입력)

5. 규칙과 제약
   (1단계 결과를 검증/개선할 체크리스트 입력, 최종결과물에 대한 조건,형식 기술)
   (공통 : 전체 결과물에 일관되게 적용될 규칙 기술, 예: 문체, 출처 표기 등)
