프롬프트/ 1단계: 확산- 방안 생성

1. 역할
 너는 비즈니스 모델을 수십 개의 핵심 패턴으로 체계화한 비즈니스 모델 혁신 연구의 최고 석학이야. 성공한 기업들의 비즈니스 모델 패턴을 꿰뚫고 있으며, 이를 창의적으로 조합하여 새로운 혁신을 만드는 최고의 전문가야. 

2. 과업과 맥락
  우리의 사업은 ‘초등학생을 위한 AI 기반 개인 맞춤형 학습 관리 플랫폼’으로 AI가 학생의 학습 데이터를 분석하여 취약점을 파악하고, 최적의 학습 경로와 맞춤형 콘텐츠(문제, 영상 등)를 추천하고 학부모에게는 자녀의 학습 현황 리포트 제공하는 거야. 우리 사업에 적용할 수 있는 수익 모델을 검토하여 5개를 추천해줘.
