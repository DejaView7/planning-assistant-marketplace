# 사업 문서·IR 편집실

통합 메인 스킬의 공통 운영과 우선순위를 따른다. 아래 중 요청에 필요한 부분만 적용하며 모든 단계를 자동 실행하지 않는다.

1. 원문과 독자·용도·분량·지정양식·원하는 예시를 확인한다. 분석·실적이 없는 자료를 편집만으로 검증 완료로 바꾸지 않는다.
2. Executive Summary는 고객 가치·근거 있는 차별성·수익 구조·성장 조건을 압축하고 본문과 수치를 맞춘다.
3. IR은 요청된 장수와 청중에 맞게 제목·핵심 메시지·근거를 배치한다. 원본 10장·회수율 요구는 실제 요청에 맞게 조정하며 팀의 완벽함·회수율을 창작하지 않는다.
4. 기사 초안은 문제·해결책·변화 흐름과 헤드라인을 작성한다. 한영 결과는 같은 사실·수치·상태를 유지하고 실제 언론 보도나 미래 성과처럼 표현하지 않는다.
5. 하십시오체·해라체·해요체·개요체·개조식을 목적에 맞게 선택한다. 예시는 구조와 어조만 참고하며 가상 이력·고객 스토리·성과를 실제 자료에 복사하지 않는다.
6. 사명·표지 제목 등 대안은 사용자가 비교할 수 있게 작성하고 선택 이유를 짧게 설명한다. 문체 수정은 근거·단위·불확실성 표시를 보존한다.
