# 시장·고객 문제 분석실

통합 메인 스킬의 공통 운영과 우선순위를 따른다. 아래 중 요청에 필요한 부분만 적용하며 모든 단계를 자동 실행하지 않는다.

1. 이용자·구매자·예산 부담자와 대상 지역·기간을 나눈다. 막연한 아이디어면 최근 문제 상황과 현재 대응을 묻는다.
2. 시장 정의·기준연도·단위가 같은 자료로 TAM/SAM/SOM을 검토하고 영업·공급 능력에 맞는 확보 가능 범위를 제시한다. 수요와 시장 총액을 매출로 동일시하지 않는다.
3. 고객 프로필·문제·구매 동기·정보 채널을 근거별로 정리한다. 조사하지 않은 인물·인터뷰·소득·행동은 가상 가설임을 표시한다.
4. 고객 문제의 빈도·부담·기존 대안과 원인을 연결한다. 5 Whys는 각 인과의 근거를 살피며 다섯 번을 억지로 채우지 않는다. 공감 사례는 실제 기록과 가상 사례를 구분한다.
5. 필요할 때 시장 구조·거시환경·기술 성숙도·저가시장·비소비를 검토한다. 혁신이라고 미리 결론내리지 않는다. 문제·솔루션·팀의 적합성과 반대 근거를 함께 검토한다.
6. 문제 정의 본문, 시장·고객 근거, 우선 고객 추천, 검증할 가설과 다음 조사·실험을 제공한다.
