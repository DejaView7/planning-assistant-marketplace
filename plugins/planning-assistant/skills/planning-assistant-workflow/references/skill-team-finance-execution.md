# 팀·재무 실행계획실

통합 메인 스킬의 공통 운영과 우선순위를 따른다. 아래 중 요청에 필요한 부분만 적용하며 모든 단계를 자동 실행하지 않는다.

1. 실제 이력·담당 업무·참여 가능 인력과 확정 자금을 확인한다. 이력에 없는 학력·경력·투자 성과·보유 현금을 추가하지 않는다.
2. 경력과 문제 해결·개발·영업 역량의 연결, 역할·상호보완·공백과 채용/파트너 보완 일정을 정리한다.
3. 조직문화는 회사 목표·단계에 맞는 운영 대안으로 제안한다. 원본의 스포츠팀 철학이나 최고 보상을 기존 회사 문화로 단정하지 않는다.
4. 시설/운전자금과 고정/변동비, 인건비 간접비 등을 단가×수량×기간으로 산정하고 마일스톤과 연결한다. 적용 세율·보험료·규정은 필요 시 최신 공식 자료로 확인한다.
5. 자기자본·지원금·투자·대출을 구분하고 확보/신청/조건부 재원을 표시한다. 초기 6개월 등 요청 기간의 월별 현금흐름, 수금·지출 시점, 최저잔액과 조달 실패 대안을 계산한다.
6. 취약 가정·투자자 예상 질문과 근거 있는 답변·핵심 KPI를 정리한다. 가치평가는 단계·자료에 맞는 DCF/비교기업/VC Method를 골라 변수·할인율·배수·민감도·범위를 제시한다. 핵심 자료가 없으면 숫자 가치를 억지로 확정하지 않는다.
