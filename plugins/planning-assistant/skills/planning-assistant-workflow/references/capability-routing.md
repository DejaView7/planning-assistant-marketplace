# 연결과 실행 환경

중앙 MCP나 특정 회사 계정을 필수로 요구하지 않는다. 플러그인은 지침만 배포한다. 사용 가능한 도구와 실제 자료 접근 범위를 해당 작업 시점에 확인한다. 자료 접근과 문서 처리는 별개이며 Drive 연결 성공이 HWP 표 편집 성공을 뜻하지 않는다.

| 기능 | 확인할 범위 | 사용할 수 없을 때 |
| --- | --- | --- |
| 첨부·로컬 파일 읽기 | 실제 본문·표·이미지·쪽별 추출 범위 | 가능한 형식의 사본·추출 경로를 확인하고 미확인 범위를 밝힘 |
| 웹 조사 | 실제 검색·원문 열람 가능 여부와 확인일 | 제공된 자료로 작업하고 최신 확인을 수행했다고 주장하지 않음 |
| 공용 저장소 | 사용자가 요청한 위치·계정 권한·실제 검색과 본문 조회 | 이미 제공된 첨부를 활용. 검색 결과 제목만으로 본문을 읽었다고 말하지 않음 |
| 문서 편집·생성 | 원본 형식의 쓰기 지원, 대상 셀·문단 식별, 저장·재읽기 | 지원되는 검토본 형식 또는 실제 본문 제공. 확장자만 변경하지 않음 |
| 결과 검증 | 텍스트·수치 확인과 렌더링·시각 확인을 각각 수행할 수 있는지 | 검증한 부분과 남은 검증을 보고 |

자료 검색은 사용자가 지정했거나 해당 업무에 필요한 범위로 한정한다. 개인 계정·폴더·서비스를 고정하지 않는다. 연결되지 않은 앱 설치나 로그인을 모든 요청의 선행 조건으로 만들지 않는다. 기능 확인이 필요하지 않은 짧은 상담은 바로 답한다.

접근 권한이 필요한 경우 필요한 연결과 범위를 구체적으로 알리고, 답변에 의존하지 않는 작업을 이어간다. 사용자 지정 없이 회사 자료를 외부 서비스에 업로드하거나 공유 범위를 확대하지 않는다. 다른 사람의 파일 권한을 공용 관리자 계정으로 대신하지 않는다.

도구가 제공되지 않은 환경에서도 작성 가능한 본문을 준비하되 자동 변환·편집·저장을 약속하지 않는다. 새 환경의 실제 문서 실행 시험 전에는 모든 환경에서 동일하게 작동한다고 보장하지 않는다. [업무별 결과물 기준](task-delivery.md)을 적용한다.
